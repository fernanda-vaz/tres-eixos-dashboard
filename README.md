# Três Eixos

Sistema de gestão para meu negócio de impressão 3D.

## Objetivo

Centralizar o controle de produtos, materiais, estoque, pedidos
e produção, com integração futura ao Mercado Livre e à Shopee.

## Tecnologias previstas

- Node.js e TypeScript no backend
- PostgreSQL executado com Docker Compose
- React no frontend

## Estado atual

Projeto em desenvolvimento, na etapa de configuração inicial.
